# Entrega 0011 - Changelog

## Objetivo

Adicionar uma area de Changelog ao portal para que usuarios autenticados possam consultar, pela interface, todas as mudancas realizadas no projeto.

## Escopo Implementado

- Criado item de menu `Changelog`.
- Criado controller autenticado `ChangelogController`.
- Criado `ChangelogViewModel`.
- Criada view `Views/Changelog/Index.cshtml`.
- Criada apresentacao em linha do tempo com entregas, resumo, mudancas e notas tecnicas.
- Adicionados estilos especificos para resumo e cards do changelog.
- Criado arquivo `docs/CHANGELOG.md` para manter o historico tambem em Markdown.

## Resultado

O portal agora possui uma tela dedicada para acompanhamento de evolucao do MVP, permitindo consultar detalhadamente o que foi entregue desde a fundacao tecnica ate as funcionalidades mais recentes.
