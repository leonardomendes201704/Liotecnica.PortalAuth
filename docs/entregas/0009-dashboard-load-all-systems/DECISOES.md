# Decisoes - Entrega 0009

## Sem Limite Fixo No Dashboard

O dashboard nao deve esconder sistemas ativos por limite fixo de exibicao.

Quando a lista crescer, a solucao correta sera adicionar:

- busca;
- favoritos;
- paginacao;
- categorias;
- ordenacao configuravel.

## Mantido Filtro De Ativos

O dashboard continua exibindo apenas sistemas com:

- `is_active = true`;
- `is_deleted = false`.
